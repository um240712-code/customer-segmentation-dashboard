# لوحة تحليل العملاء (RFM + K-Means)

تطبيق Streamlit عربي يقسّم العملاء إلى 4 شرائح حسب **آخر شراء (Recency)** و**تكرار الشراء (Frequency)** و**حجم الإنفاق (Monetary)**، ويعرض رؤى وتوصيات تسويقية جاهزة.

## المميزات
- نظرة على الشرائح: مؤشرات، رؤى ذكية، رسوم متحركة، ومنحنى 80/20
- الاتجاهات: الإيرادات الشهرية حسب الشريحة، أفضل المنتجات والدول
- تصنيف عميل جديد، أو ملف كامل من العملاء دفعة واحدة
- البحث عن عميل برقمه
- مخطط حملة تسويقية مع العائد المتوقع وقائمة مستهدفين
- جودة النموذج: Elbow و Silhouette
- تصدير CSV وتقرير HTML قابل للطباعة PDF

## الشرائح
| الشريحة | المعنى | الإجراء |
|---|---|---|
| كبار العملاء (VIP) | يشترون كثيراً وبمبالغ كبيرة وبشكل حديث | مدير حساب وعروض حصرية |
| العملاء الأوفياء | إنفاق جيد وتكرار ثابت | برنامج نقاط ومنتجات مكمّلة |
| عملاء واعدون | اشتروا مؤخراً بإنفاق متواضع | حوافز للطلب التالي |
| معرّضون للخسارة | غابوا فترة طويلة وإنفاقهم قليل | حملة استعادة |

## التشغيل
```bash
pip install -r requirements.txt
# ضع ملف البيانات الخام في data/data.csv
python run_pipeline.py        # تنظيف + RFM + تدريب النموذج
streamlit run app.py
```

## الاختبارات
```bash
pip install pytest
pytest
```

## هيكل المشروع
```
app.py              واجهة التطبيق
preprocess.py       تنظيف البيانات
model_training.py   حساب RFM
cluster_model.py    تدريب K-Means وتجهيز ملفات الاتجاهات والمقاييس
run_pipeline.py     تشغيل الخطوات الثلاث بالترتيب
tests/              اختبارات
.streamlit/         إعدادات المظهر
data/  models/      البيانات والنماذج
```

## النشر على Streamlit Community Cloud
1. ارفع المشروع على GitHub (الملفات الكبيرة مستثناة في `.gitignore`).
2. تأكد أن هذه الملفات موجودة في المستودع: `data/rfm_clustered.csv` و`data/trends_monthly.csv` و`data/top_products.csv` و`data/top_countries.csv` و`data/model_metrics.json` و`models/*.pkl`.
3. من share.streamlit.io اختر المستودع والملف `app.py` ثم Deploy.
4. إن ظهر خطأ في تحميل النموذج، ثبّت في `requirements.txt` نفس إصدار `scikit-learn` الذي دربت به محلياً (`pip show scikit-learn`).
